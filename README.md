# SABHAN AI PRO — Image Translation & Text Replacement

## ماذا تفعل؟
- OCR وتحليل مواقع النص داخل الصورة.
- ترجمة كل منطقة نصية إلى اللغة المختارة.
- إعادة وضع النص المترجم داخل نفس الإحداثيات تقريباً.
- دعم اتجاه RTL.
- تنزيل الصورة الناتجة.
- مفتاح API يبقى في الخادم.

## التشغيل
1. ثبّت Node.js 18+.
2. `npm install`
3. انسخ `.env.example` إلى `.env`.
4. ضع `OPENAI_API_KEY`.
5. `npm start`
6. افتح `http://localhost:3000`.

## ملاحظة الجودة
النسخة المرفقة تستخدم إعادة تركيب محلية للخلفية. على الخلفيات البسيطة تعطي نتيجة جيدة، أما الصور التي تحتوي على أشخاص/مناظر/خلفيات معقدة خلف النص فتحتاج خطوة Inpainting مخصصة للحصول على إزالة للنص الأصلي أكثر واقعية. البنية مجهزة لإضافة هذه الخطوة لاحقاً.
